Install in a minute

Use the installer for Start menu and desktop shortcuts, or the portable ZIP if you prefer to run it from any folder. Neither needs admin rights.

  1. Download the installerClick Download for Windows. It's about 599 MB because it includes its own browser engines.
  2. Run GameBrowser-Setup-windows-x64.exeWindows may show a SmartScreen warning because this preview isn't signed. Choose More info, then Run anyway. It installs to your user folder, so no admin password is needed.
  3. Open GameBrowserUse the Start menu or desktop shortcut. A console window opens, followed by the dashboard in your browser. Keep the console open while you work; closing it stops every profile.
  4. Create profiles and pick an adminClick New profile, start the profiles, then choose your admin in the Following bar.

Prefer no installer? Download the portable ZIP (811 MB), extract it, and run GameBrowser.exe. Keep the runtime, cloakbrowser and firefox folders next to it.

Questions

Windows says the app is unrecognised. Is that normal?

Yes. This is an unsigned preview build, so SmartScreen warns the first time. Choose More info, then Run anyway. You can compare the file's SHA-256 with SHA256SUMS.txt on the release page.

The dashboard says port 8080 is in use.

Another app, usually StakeMode, is using the port. Close it, then start GameBrowser again.

A follower keeps dropping off.

Press Reload all so every profile is on the same page, then Resume. If one profile keeps failing, stop and start it. The yellow advice box on the profile explains the exact cause.

Where are my profiles stored?

In %LOCALAPPDATA%\GameBrowser, separate from the program folder. Installing a newer version over the old one keeps your profiles, and uninstalling leaves them in place too.

Can I build it myself?

Yes. The full source is on GitHub under the Apache 2.0 license. You need Bun 1.3 or newer; the README has the build command.
